## 第一次上传与发布

1. 把本文件所在目录的全部内容上传到 GitHub 仓库根目录。保留 `assets/` 文件夹及图片。
2. 在仓库 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。
3. 等待 Pages 部署完成，打开设置页面实际给出的网址。不要把仓库文件页面当成图库网址。
4. 在图库里点击“复制查看链接”，发送给设计师。

GitHub 免费账号的 Pages 通常使用公开仓库；公开仓库及公开网站中的图片、分析和偏好均可被他人访问。查看模式只隐藏编辑按钮，不提供身份或密码保护。只有拥有 Git 仓库写入权限的人能更改线上文件。

## 日常使用

- **全部参考**：按原文件名看图，搜索文字，并按空间、元素类别和偏好组合筛选。
- **逐图分析**：点击图片进入“大图＋元素说明”，支持放大、上一张／下一张、查看或下载原图。
- **元素位置联动**：在详情中点击元素卡片或“定位”，图片显示对应位置；同一元素涉及多处时显示多个编号点，整体配色等显示整图或场景范围。再次点击或“清除选择”可隐藏标记。当前 139 张图片的 916 个元素均已补充位置参考。
- **手机端对照**：图片固定在详情上部，下面的元素列表独立滚动，点选元素时仍能看到图片上的位置。
- **分享具体元素**：选择元素后复制浏览器地址，对方打开会直接看到同一张图片及该元素的位置。仅定位不会改变喜好或产生本机草稿。
- **简洁展示**：整图默认只显示标题和色彩标签；元素默认只显示分类、名称、位置与操作按钮。详细分析保留在编辑窗口中，个人备注点击后展开，打印清单也采用简洁格式。
- **元素偏好**：每个元素分别标记喜欢、待考虑、不喜欢，或清除标记；收藏整张图片与元素偏好分开。
- **修改分析**：修改整图说明、单个元素，补充新元素、个人备注及想应用的空间。
- **元素分类**：同一张图中的不同元素分别进入对应分类。
- **材质细类**：材质与肌理进一步分为石质、木质、瓷砖、墙面、金属、玻璃与镜面、织物与软包、编织、其他／待确认，可按细类和通用类型筛选。
- **通用材质类型**：同种材质选用同一个类型。例如不同图的木纹统一引用“木纹饰面”，颜色和位置写入“本图表现”。修改通用名称与说明会同步到全部引用，逐图的喜好、备注仍分别记录。新类型可以在“元素分类”页创建，再在单图分析中选用。
- **我的偏好**：以大图展示已标记元素，卡片只显示元素名称和当前偏好标签。文件名、位置及备注在详情中查看，偏好也在详情中调整。
- **自适应偏好卡片**：宽屏（1200px 起）每排 3 个，中等屏幕和手机每排 2 个，均使用大图在上、简短信息在下的结构，完整预览图片。
- **偏好详情**：从“我的偏好”进入图片时，只显示所点卡片对应偏好类型的元素。上一张、下一张严格跟随当前筛选后可见卡片的顺序，同图不同元素按各自卡片切换并定位；在“全部偏好”中切换时，详情随新卡片显示对应类型。筛选、搜索及当前卡片会保留在分享地址中，刷新后仍能按同一顺序查看。从“全部参考”进入仍显示完整分析。
- **删除图片**：图片详情中点击“删除图片”，确认后从图库及偏好清单中移除整张图。可在提示中立即撤销，也可在当前会话的“导出更新”窗口撤销最近一次删除。撤销会保留原来的图片顺序、标记和备注。删除会保存为本机草稿，刷新后仍有效；上传导出的 data.js 后，分享网页同步移除。原图文件保留在 Git 仓库中，可另行清理。
- **打印沟通清单**：仅输出已标记元素，可在浏览器打印窗口选择另存为 PDF。
- **添加参考图**：批量添加 JPG、PNG、WebP、GIF，单张最多 20MB。新增图片默认待分析，不自动生成或调用 AI。上传到 Git 前，新图片暂存在当前浏览器。

新增元素默认未标记，保留原有个人选择。仅凭照片不能确认的实际材质已明确注明，不把材质外观当作真实石种、木种、品牌或具体工艺。

## 修改后如何同步到其他电脑

网页没有数据库或在线写入服务。修改首先保存在当前浏览器草稿，顶部显示“有待上传的本机草稿”，不会自动改变 Git 仓库。

**只改偏好、备注或分析：**

1. 点击“导出更新”→“只导出更新文件 · data.js”。
2. 把下载的 `data.js` 上传到仓库根目录，替换同名文件并提交。
3. 等待 Pages 部署完成。在其他电脑刷新线上网页即可查看。

**添加过新图片：**

1. 点击“导出更新”→“导出更新包 · ZIP”。
2. 解压，把 `data.js` 上传到仓库根目录，把 `assets/` 中的新图片上传到仓库同名文件夹。
3. 保留已有的网页文件及原图，等待 Pages 更新。

更新包只包含本次资料文件和本机新添加的图片，不重复包含已有原图。下载成功不等于已经上传。导出 JSON 是资料备份，不包含图片，可在另一台电脑导入标记。

```text

styles.css          响应式样式与打印版式
app.js              浏览、筛选、标记、编辑、导入及更新包导出

data.js             图片资料、分析、偏好及备注

thumbs/             小尺寸预览图，列表按需加载；详情仍显示原图
参考图清单.md        全部图片的文件名、类型、标题与元素数量
.nojekyll           让 GitHub Pages 直接发布静态文件
```

## 草稿与版本

- 本机文字草稿保存在浏览器 localStorage，新图片保存在 IndexedDB。
- 清理浏览器数据、无痕模式、换浏览器或换电脑可能导致本机草稿不可用，请及时导出并上传。
- 新版 `data.js` 带独立版本标识。刷新后优先加载已上传的新版本，旧版本草稿不会自动覆盖它。
- 从首批 4 图、93 图版本或上次已发布偏好版本升级到当前版本时，会合并新增图片与材质类型，保留旧草稿中的标记、备注、自定义类型、本机新增图片和删除记录。
- 多人分别修改并上传 `data.js` 时，后上传的文件可能覆盖另一份修改；建议由一人统一维护，或先合并资料。
- 支持直接打开 `index.html` 浏览。对外分享请使用发布后的网页网址，本地文件路径不能分享给他人访问。

## 按添加日期查看

筛选栏支持按图片加入图库的日期查看，日期按新到旧排列，可与空间、材质和偏好组合筛选。复制查看链接保留日期；例如 `?view=preferences&date=2026-11-09&mode=view`。历史图片按已有批次补记为 2026-11-02、2026-11-03 和 2026-11-09；以后网页新增图片自动记录当天日期，修改偏好或备注不改变添加日期。旧草稿缺少日期时按原图片编号补回；无法确认的日期显示“未记录日期”。
